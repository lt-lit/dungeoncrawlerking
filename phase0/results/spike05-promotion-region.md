# Spike 5 — Per-color promotionRegion = enemy back rank

**Question (§9.5):** "Per-color `promotionRegion` = enemy back rank on generated boards."

**Script:** `spikes/spike05-promotion-region.mjs` (15/15 checks pass).
**Builds:** ffish.js `010526 LB`; engine `5589ea54 LB`; classical eval.

## Verdict: PASS.

## Findings

1. **`promotionRegionWhite = *<ranks>` / `promotionRegionBlack = *1` works exactly
   as intended** on 8x8, 5x7, and 12x10: pawns promote precisely on the enemy back
   rank, never a rank early, both colors.
2. **Default promotion targets inherited from the chess template: q, r, b, n**
   (SAN `e8=Q+` style). This is the answer to the `[OPEN]` promotion-targets
   question's baseline — full chess promotion until design says otherwise.
3. **`promotionPieceTypes` is a working restriction lever** (`= n` → knight-only
   promotion). Per-duel promotion tables are one ini line away if the design wants
   them (e.g. collection-based targets later).
4. **Walls on the back rank behave:** a pawn cannot push onto a wall square
   occupying its promotion square, but capture-promotions into adjacent non-wall
   region squares work. Clipped arenas need no special promotion handling.
5. **Engine behavior:** in a won K+P ending the engine shepherds and promotes
   (`e7e8q`, mate score). No reluctance or artifacts.
6. **UCI note for 10-rank boards:** squares on rank 10 are 3 characters (`f10`),
   so promotion moves run 6+ chars (`f9f10q`). Any move-string parsing must use a
   proper square regex, not fixed offsets — this bit the harness once already
   (fixed in `harness/crumble.mjs`, now `harness/legacy/crumble.mjs`).

## Design implications

- Baseline stays as generated by `lib/variant.mjs`. Promotion "lanes" outside the
  enemy patch exist by design (regions are board-level, not patch-level) — the
  threat display should read promotion pressure from board geometry, not patch
  geometry.
- If promotions need theming per enemy book/boss, `promotionPieceTypes` is the
  lever; no FEN or harness changes required.
